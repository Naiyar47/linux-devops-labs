Linux is an operating system used to manage servers, cloud infrastructure containers, and applications.
Kernel is The core of Linux. It manages hardware (CPU, memory, devices) and lets software talk to hardware. acts as  a bride b/w software and hardware.  see the kernel version using uname -r
Shell is the program that takes our commands and tells the kernel what to do. 
Filesystem : How linux organizes files and folders. everything is in a tree starting from / (root).
